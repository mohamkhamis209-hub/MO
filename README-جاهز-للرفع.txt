منصتك التعليمية - نسخة جاهزة للرفع

1) ارفع جميع الملفات كما هي إلى GitHub.
2) افتح index.html من خلال GitHub Pages أو سيرفر HTTP، ولا تفتح الملفات بصيغة file://.
3) Firebase موجود في js/firebase-config.js.
4) لوحة المشرف: admin-login.html
5) دخول الطالب: student-login.html
6) إضافة الأسئلة من صورة: من لوحة المشرف > 📷 إضافة أسئلة من صورة.

التعديلات المدمجة:
- إنشاء الطالب يعطيه كودًا فورًا داخل مربع مع زر نسخ.
- الحساب الجديد غير نشط حتى أول تسجيل دخول بالكود.
- الكورسات المتاحة للصف تدخل مباشرة بدون طلب موافقة.
- Telegram للكتب: لا يفتح تلقائيًا؛ الطالب يضغط بنفسه على فتح/تحميل.
- استيراد سؤال/عدة أسئلة من صورة مع اختيار نوع السؤال والإجابة الصحيحة.

تحديث تسميع الكلمات (الملفات مدمجة تلقائيًا):
- ملفات JSON الأربعة موجودة داخل مجلد vocabulary.
- افتح لوحة المشرف أو قسم تسميع الكلمات في لوحة الطالب بعد نشر المشروع؛ ستُنشأ المجموعات الافتراضية تلقائيًا في Firestore.
- لا يلزم نسخ روابط GitHub Raw أو إعداد كل مجموعة يدويًا.
- ارفع مجلد vocabulary كاملًا مع ملفات المشروع، وحافظ على أسماء الملفات والمسارات.
- الملفات المصدرية الأصلية موجودة في vocabulary/original-html.


تحديث V19: في لوحة المشرف تظهر أسماء ملفات الكلمات بجانب الروابط، ويمكن إضافة مجموعة جديدة بلصق رابط JSON مباشر. يجب أن يكون الرابط متاحًا للقراءة من المتصفح (CORS عند الاستضافة الخارجية).


تحديث V20 - التحكم في ظهور التسميع للطلاب:
- مجموعات ملفات الكلمات المدمجة تكون مخفية عن الطلاب افتراضيًا.
- من لوحة المشرف > تسميع الكلمات، فعّل مربع (تفعيل التسميع للطلاب) للمجموعة التي تريد إسنادها فقط ثم احفظ.
- الطالب يرى مجموعات التسميع المفعّلة المطابقة لصفه فقط، ولا تظهر له قائمة ملفات المشروع نفسها.
- عند أول فتح لقسم التسميع بعد التحديث، يتم إيقاف المجموعات المدمجة القديمة تلقائيًا مرة واحدة؛ راجع لوحة المشرف وفعّل المطلوب.


تحديث V21: في لوحة المشرف > تسميع الكلمات يوجد زر «عرض ملفات الكلمات الموجودة واختيار ملف». تظهر الملفات المعرفة في vocabulary/files.json، وعند اختيار ملف يتم تعبئة الرابط واسم المجموعة تلقائيًا. يمكنك أيضًا لصق رابط JSON خارجي في خانة الرابط كما قبل. لإضافة ملف محلي جديد للقائمة، ارفع ملف JSON إلى مجلد vocabulary ثم أضف اسمه ومساره وعدد كلماته إلى vocabulary/files.json.
