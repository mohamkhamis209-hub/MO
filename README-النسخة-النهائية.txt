منصتك التعليمية — النسخة النهائية الجاهزة للرفع

أهم ما تم تضمينه:
- تسجيل الطالب وكود الطالب ومربع النسخ والتفعيل عند أول دخول.
- لوحة الطالب والقائمة الجانبية والكورسات المباشرة حسب الصف بدون طلب موافقة.
- الفيديوهات مرتبة داخل الكورسات وحفظ تقدم المشاهدة والسابق/التالي والتكبير والتشغيل التلقائي.
- امتحان مرتبط بفيديو: يظهر مباشرة أسفل الفيديو ويمكن للطالب بدءه من نفس صفحة الدرس.
- كتب عامة للكورس أو مرتبطة بفيديو/درس.
- دعم Google Drive وTelegram للكتب، وTelegram لا يفتح إلا عند ضغط الطالب.
- اختبارات عامة للكورس أو مرتبطة بفيديو/درس.
- أسئلة عامة تحت الفيديو مع ردود الطلاب وإجابة المشرف المثبتة.
- أسئلة خاصة للمشرف محفوظة في Firestore وتظهر في الطلبات المعلقة، مع استمرار زر WhatsApp.
- الطلبات المعلقة: تسجيلات قديمة + أجهزة جديدة + الأسئلة الخاصة + الطلبات القديمة إن وجدت.
- المشرفون المساعدون وصلاحياتهم، وقسمهم للمشرف الأساسي فقط.
- إضافة الأسئلة من صورة: OCR عربي/إنجليزي، فصل عدة أسئلة، مراجعة وتعديل، MCQ / صح وخطأ / مقالي / قصير / نوع آخر، وتحديد الإجابة.
- أداة OCR تدعم ربط الاختبار بالكورس وبفيديو محدد وحفظ صورة المصدر.
- ImgBB لصور الكورسات والدروس والكتب.
- اللوجو وصورة مؤسس المنصة mo.jpg.

الرفع:
1) ارفع محتويات هذا المجلد إلى GitHub.
2) استخدم GitHub Pages أو أي HTTP/HTTPS وليس file://.
3) Firebase config موجود في js/firebase-config.js.
