قسم تسميع الكلمات — دليل سريع

1) ارفع ملف الكلمات إلى مستودع GitHub عام بصيغة JSON.
2) افتح الملف على GitHub ثم اضغط Raw وانسخ الرابط الذي يبدأ بـ:
   https://raw.githubusercontent.com/USERNAME/REPOSITORY/BRANCH/path/words.json
3) ملف JSON يجب أن يحتوي على قائمة كلمات، وكل كلمة تحتوي على الكلمة الإنجليزية والمعنى العربي.
   مثال:
   [
     { "en": "apple", "ar": "تفاحة" },
     { "en": "book", "ar": "كتاب" }
   ]
   ويمكن استخدام english و arabic بدل en و ar.
4) من لوحة المشرف افتح «تسميع الكلمات» ثم أدخل اسم المجموعة، رابط Raw، الصف، الكورس، رقم البداية والنهاية، وعدد الكلمات اليومية.
5) اضغط «اختبار رابط الملف» قبل الحفظ. الطالب يرى المجموعات المفعّلة المطابقة لصفه فقط.
6) اتجاه السؤال عشوائي: عربي إلى إنجليزي أو إنجليزي إلى عربي. يتم تصحيح الإجابة الكتابية تلقائيًا.
7) تحفظ المحاولة اليومية في Firestore، ويمكن للطالب استكمال محاولة بدأها ولم يسلّمها. بعد التسليم لا يمكنه بدء محاولة أخرى لنفس المجموعة في نفس اليوم.
8) لا تُعاد الكلمات التي سمعها الطالب بالفعل حتى ينتهي النطاق المحدد؛ بعد انتهاء جميع الكلمات يبدأ النظام دورة جديدة.

ملاحظات:
- يجب أن يكون مستودع GitHub عامًا كي يستطيع الموقع قراءة الملف دون تسجيل دخول.
- إذا كان الملف PDF فقط، حوّل الكلمات إلى JSON أولًا. مثال ملف JSON مرفق باسم vocabulary-example.json.
- بيانات المجموعة ومحاولات الطلاب والنتائج محفوظة في Firestore ضمن المجموعات:
  vocabularyAssignments, vocabularyAttempts, vocabularyProgress
