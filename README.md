# منصة تانية بكالوريا — الإصدار الاحترافي

## الجديد
- دخول الطلاب بالاسم الثلاثي + كود شخصي إلزامي.
- إنشاء كود يدوي أو عشوائي وتغييره من لوحة الإدارة.
- منع دخول الطالب نفس الامتحان مرتين على مستوى السيرفر، حتى مع الضغط المتكرر.
- زر طلب كود عبر واتساب: 01033459821.
- قسم فيديوهات: YouTube / Shorts / Vimeo / MP4-WebM-Ogg مباشرة.
- حذف مستقل للامتحانات والنتائج والكتب والفيديوهات والطلاب.
- مربع كلمة مرور احترافي مع زر إظهار/إخفاء.
- محرر أسئلة احترافي بدون prompt.

## Google Apps Script
1. استبدل Code.gs في Apps Script بالكود الموجود هنا.
2. شغّل setup() مرة واحدة. سيُنشئ Books وVideos وStudents ويحدّث Attempts للحفاظ على النتائج القديمة.
3. تأكد أن Script Property باسم ADMIN_TOKEN تحتوي كلمة مرور الإدارة.
4. حدّث نشر Web App إلى إصدار جديد (Access: Anyone حسب إعداد حسابك).
5. لا تغيّر API_URL في index.html؛ هو نفس رابط Web App الحالي.
