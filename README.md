# منصة تانية بكالوريا — النسخة الجاهزة لـ GitHub Pages

هذه النسخة تعمل من **GitHub Pages فقط**، بدون Render أو Vercel أو Railway.

## رفعها على GitHub

1. فك الضغط.
2. أنشئ Repository جديدًا على GitHub.
3. ارفع **كل الملفات الموجودة داخل هذا المجلد** إلى الفرع `main`.
4. افتح:
   **Settings → Pages**
5. في **Build and deployment** اختر:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/ (root)`
6. اضغط **Save**.
7. افتح رابط GitHub Pages الذي سيظهر لك.

## الملفات

- `index.html` — الموقع كاملًا.
- `mo.png` — صورة محمد خميس مدمجة داخل المشروع.
- `.nojekyll` — لضمان تقديم الملفات بشكل صحيح.
- `404.html` — تحويل بسيط للموقع.
- `.gitignore`
- `README.md`

## تنبيه مهم

لأنها نسخة GitHub Pages فقط، لا توجد قاعدة بيانات مركزية. بيانات الامتحانات والنتائج التي تضيفها من لوحة الإدارة تُحفظ في `localStorage` على نفس المتصفح والجهاز.

استخدم النسخ الاحتياطي من لوحة الإدارة إذا أضفت بيانات مهمة.
